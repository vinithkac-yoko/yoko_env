# Tools

Every tool the drafting agent can use, in plain words. Written from `config/tools/*.yaml` (`uv run python scripts/tool_catalog.py`); do not edit this file by hand.

**Please check the names.** They are the words the agent sees. If a name is not the word you would use, say which one and what you would call it.

Every tool that makes a point, line, arc or curve also has an `edit_<tool>` (change its numbers or what it refers to) and a `delete_<tool>` (remove it, refused if anything uses it). They are made from the creating tool, so they are not listed again.

## Points

| Tool | What it does | When to use it |
| --- | --- | --- |
| `cut_arc` | Create a point at a given length along an arc, splitting the arc in two at that point. | a point must sit a set distance along an arc |
| `cut_curve` | Create a point at a given length along a single curve (a spline or Bezier), splitting it into two curves at that point. | a point must sit a set distance along a curve, for example a notch or a dart start |
| `cut_curve_path` | Create a point at a given length along a path of several splines, splitting it in two at that point. | the curve is a spline path or Bezier path (its name starts with SplPath_) |
| `point_along_line` | Create a point on the straight line from one point to another, at a given distance from the first. | you need a point somewhere along an existing line, for example the middle (length = half the line) |
| `point_arc_arc` | Create a point where two existing arcs cross. | two arcs already drawn must meet |
| `point_arc_line` | Create the point where a circle drawn round a centre point meets the line between two points. | you know a distance from a point and want where it lands on a line, for example a shoulder length measured from the neck point |
| `point_arc_tangent` | Create the point where a line drawn from a point just touches an existing arc (a tangent). | a straight line from a point must touch an arc already drawn |
| `point_at_distance_angle` | Create a point at a given distance and direction from an existing point, and draw a line to it. | you know how far and in which direction the new point lies from another point |
| `point_bisector` | Create a point on the line that halves the angle formed by three points, starting at the middle point. | you need the direction that splits a corner in two equal angles |
| `point_circle_circle` | Create a point where two circles drawn round two centre points meet. | a point must be a set distance from two different points, for example a dart point or a sleeve cap notch |
| `point_circle_tangent` | Create the point where a line drawn from a point just touches a circle (a tangent). | a straight line from a point must touch a circle without crossing it |
| `point_curve_axis` | Create the point where a straight line through a base point at a given angle crosses a curve or an arc. It also cuts the curve in two at that point. | a horizontal or vertical line from a point should meet a curve, for example finding where a level line meets an armhole |
| `point_curve_curve` | Create a point where two curves (or arcs) cross. | two curves must meet, for example a new style line and an existing seam |
| `point_from_xy` | Create a point that takes its horizontal position from one point and its vertical position from another. | you want the corner of a rectangle built from two existing points |
| `point_height` | Create the foot of the perpendicular: the point on the line between two points that is nearest to a base point. | you need the square drop from a point onto a line |
| `point_line_axis` | Create the point where a straight line through a base point at a given angle crosses the line between two other points. | you need a horizontal or vertical line (or any angle) from a point to meet another line |
| `point_line_line` | Create the point where the line through two points crosses the line through two other points. | two straight lines cross and you need the crossing |
| `point_origin` | Create a free point at fixed coordinates, measured from the page origin. Normally one per drafting block. | you start a new drafting block that hangs off no other point |
| `point_perpendicular` | Create a point at a right angle to the line from one point to another, starting from the first point. | you need a square corner, for example a hem line at a right angle to the centre front |
| `point_shoulder` | Create a point on the line through two points, beyond the second one, at a set distance from a third point. A line is drawn from the line's ends to the new point. | a point on a line must be a given distance from a point off the line, as for a shoulder length measured from the neck point |
| `point_triangle` | Create the point on a line (through two points) from which the distance between two other points is seen at a right angle. | a point must lie on a given line so that it forms a right angle with two other points |
| `true_darts` | Create the two points Seamly2D's 'true darts' tool makes: where the legs of a dart end up so that, when the dart is folded closed, the seam it leaves is true. | a dart must be trued before the pattern is cut |

## Lines, arcs and curves

| Tool | What it does | When to use it |
| --- | --- | --- |
| `arc_elliptical` | Draw an arc of an ellipse round a centre point, from a start angle to an end angle, with an optional tilt of the ellipse. | you need an oval curve, for example a pocket corner or an oval neckline |
| `arc_length` | Draw an arc of a circle round a centre point, from a start angle, with a given length along the arc. | the arc must be a set length, for example to match a measured seam length |
| `arc_radius` | Draw an arc of a circle round a centre point, from a start angle to an end angle, counter-clockwise. | you need a circular curve of a known radius, for example a hem curve or a rounded corner |
| `curve_bezier` | Draw a Bezier curve between two points steered by two control points that already exist as points. | you want to steer a curve by two visible control points |
| `curve_bezier_path` | Draw a chain of Bezier curves through points given as groups of (point, control, control, point, control, control, point ...). | you already have the control points as points and want a long Bezier chain |
| `curve_spline` | Draw a smooth curve between two points. At each end you choose the direction the curve leaves in and how long the handle is (the longer the handle, the longer the curve keeps that direction). | you need a free-form curve such as an armhole, neckline or hip curve between two points |
| `curve_spline_path` | Draw one smooth curve through several points in order. At every point you choose the direction and handle lengths. | a long curve passes through three or more points, for example a whole neckline or a hem curve |
| `line` | Draw a straight line between two existing points. A line is just a drawn line: it does not create a point. | you want a visible line between two points, for example a seam or a construction line |

## Copying: mirror, rotate, move

| Tool | What it does | When to use it |
| --- | --- | --- |
| `mirror_by_axis` | Make a mirror-image copy of points, curves and arcs across a vertical or horizontal line through one point. | the mirror line is straight up and down, or level, through a point |
| `mirror_by_line` | Make a mirror-image copy of points, curves and arcs across the line through two points. | a half pattern must be mirrored into a whole one, or a piece mirrored for the other side |
| `move` | Make a copy of points, curves and arcs moved a distance in a direction, and optionally turned afterwards. | part of a pattern must be slid to a new place, for example separating pieces or spreading a slash line |
| `rotate` | Make a copy of points, curves and arcs turned by an angle about a point. | part of a pattern must be pivoted, for example closing a dart by turning one side towards the other |

## Variables

| Tool | What it does | When to use it |
| --- | --- | --- |
| `delete_variable` | Remove a variable. It is refused, with the list of formulas that use it, if anything uses it. | a variable is no longer needed and nothing uses it |
| `set_variable` | Create a named number for the pattern, or change one that exists. Other formulas can use it by name, and changing it moves everything built from it. | an amount should be one value used in several places, or a design amount (like a hem flare) should be easy to change later |

## Pieces and blocks

| Tool | What it does | When to use it |
| --- | --- | --- |
| `add_block` | Add an empty drafting block. A block is a separate working area of the pattern, usually with its own starting point. | a new piece is drafted from scratch, apart from the others |
| `add_piece` | Make a pattern piece from a closed outline of points and curves. | the lines drawn so far enclose a shape that should become a piece (a front, a sleeve, a facing) |
| `delete_block` | Delete a drafting block that has nothing in it. | an empty block is left over |
| `delete_piece` | Delete a piece. The points and curves it was drawn from stay. | a piece is not wanted |
| `rename_block` | Give a drafting block another name. | a block's name is wrong or unclear |
| `set_piece` | Rename a piece, give it a different outline, or both. Everything else about the piece stays. | a piece needs another name or its outline must follow different points or curves |
| `undo` | Take back the last change. | the last call was a mistake and nothing was built on it yet |
| `union_pieces` | Join two pieces into one along an edge of each. The second piece is moved so that its edge lies on the first piece's edge; the two pieces are replaced by the united piece. An edge is given by the point it starts at, and runs to the next point round the piece's outline. | two neighbouring pieces should become one flat piece, for example a front and a side panel, or a half pattern and its mirror |

## Looking (these never change the pattern)

| Tool | What it does | When to use it |
| --- | --- | --- |
| `dependencies` | List the objects an object was built directly from. | you want to know what an object rests on |
| `dependents` | List the objects built directly from an object. | you want to know what changes if you edit or delete it |
| `find_objects` | List objects that match: by kind, by part of the name, or by closeness to a point. | you need to find a point or curve and do not know its name |
| `get_object` | Describe one object: how it was made, its formulas, where it is or how long it is, and what it depends on or is used by. | you need to see why an object is where it is, or what an edit would affect |
| `get_state` | Summarise the pattern now: how many objects, which pieces and variables exist and their values, and any problems. | you need to know where you are before deciding the next step |
| `list_measurements` | List the body measurements the pattern is drafted for, with their values. | you need a measurement's exact name or value for a formula |
| `measure` | Measure between two points (distance and direction), or the length of a curve or arc. Millimetres and the pattern's unit are both given. | you need a current length or angle, for example to check a target amount |
| `render` | Draw the pattern as an image so you can see it. | you want to check the shape of what has been drafted |

## Library

| Tool | What it does | When to use it |
| --- | --- | --- |
| `copy_piece_from` | Copy one piece, with every point, curve and variable it depends on, from a loaded library pattern into the pattern you are working on. | a piece from another pattern is needed here, for example a sleeve from the basic set |
| `load_pattern` | Open a library pattern to look at or to copy pieces from. It does not replace the pattern you are working on. | you want to see a library pattern or copy a piece from it |
| `search_library` | Search the pattern library for patterns like a described one: by words, tags and garment type. | you are choosing a starting pattern or looking for a similar style |
